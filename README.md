## 🚀 Featured Projects

### ☁️ AWS Cloud Infrastructure

**VPC & EC2 Infrastructure**

Hands-on AWS project focused on designing and configuring a cloud infrastructure with **public and private subnets**, a frontend EC2 instance, and a backend EC2 instance.

**What I worked with:**
- Designed and configured a custom **VPC**
- Created **public and private subnets**
- Configured **Route Tables** and an **Internet Gateway**
- Deployed applications using **Amazon EC2**
- Configured **Security Groups** for controlled network access
- Restricted backend traffic to the frontend Security Group
- Configured a **NAT Gateway** to provide outbound internet access to the private backend
- Configured SSH access and troubleshooting through **port 22**

**Technologies:**  
`AWS` · `VPC` · `EC2` · `Security Groups` · `Subnets` · `Route Tables` · `Internet Gateway` · `NAT Gateway`

**Key learning:**  
This project gave me hands-on experience with AWS networking and troubleshooting. One of the main challenges was identifying that my EC2 instance was running in a different VPC from the Security Group I was trying to use. I also learned how private subnets require appropriate outbound connectivity, such as a NAT Gateway, when instances need to access external resources.
